## [Firefox 成为唯一支持 uBlock Origin 的主流浏览器](https://www.pcworld.com/article/3212428/firefox-is-now-the-last-major-browser-that-still-supports-ublock-origin.html) ⭐️ 9.0/10

谷歌 Chrome 采用 Manifest V3 后，实际上终止了对 uBlock Origin 等完整广告拦截扩展的支持，使得 Firefox 成为最后一个仍支持这些扩展的主流浏览器。 这一转变改变了浏览器市场的竞争格局，可能促使重视广告拦截的用户转向 Firefox。同时也凸显了谷歌对网络标准的控制力及其对扩展功能的限制。 Manifest V3 限制了 uBlock Origin 所依赖的 webRequest API，迫使其转向功能较弱的 declarativeNetRequest API。Firefox 承诺继续支持 Manifest V2 和 webRequest API，从而保留了完整的广告拦截功能。

hackernews · DemiGuru · 8月14日 19:03 · [社区讨论](https://news.ycombinator.com/item?id=49303202)

**背景**: Manifest V3 是谷歌 Chrome 扩展平台的最新版本，旨在提升安全性、隐私和性能。但它限制了某些 API，特别是允许扩展拦截和修改网络请求的 webRequest API。这一变化严重限制了 uBlock Origin 等广告拦截扩展的能力，这些扩展依赖该 API 在广告加载前将其屏蔽。其他基于 Chromium 的浏览器如 Microsoft Edge 和 Brave 也已采用 Manifest V3，使得 Firefox 成为唯一仍支持完整功能 uBlock Origin 的主流浏览器。
