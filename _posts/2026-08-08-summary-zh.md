## [DeepMind WeatherNext 模型将飓风预警提前一天](https://www.solidot.org/story?sid=85042) ⭐️ 8.0/10

Google DeepMind 的 WeatherNext AI 模型在《自然》杂志上发表，能够比现有模型提前一天预测飓风路径，其三天预报的准确度相当于之前模型两天的准确度。在实际测试中，该模型在飓风梅丽莎登陆前五天就以 80% 的置信度预测它将袭击牙买加。 这一突破可能显著提升应急准备能力并减少飓风造成的伤亡，因为每多一小时的预警时间都能让疏散和资源调配更加充分。同时，它也展示了人工智能在气象学中的潜力，有望变革天气预报领域。 该模型使用了大量通用天气数据而非有限的气旋数据进行训练，从而具备更强的泛化能力。WeatherNext 2 可以在不到一分钟内使用单个 TPU 生成数百种预报情景，分辨率最高可达每小时一次。

rss · Solidot · 8月8日 17:05

**背景**: 传统的飓风预报依赖于基于物理的模型来模拟大气动力学。像 WeatherNext 这样的人工智能模型则从历史数据中学习模式，通常能实现更快、更准确的预测。WeatherNext 模型家族包含多个版本，其中 WeatherNext 2 是最新的最先进模型。

## [微软 Edge 强制推行 Manifest V3，屏蔽 uBlock Origin 等扩展](https://www.solidot.org/story?sid=85038) ⭐️ 8.0/10

微软 Edge 宣布从本月开始逐步默认禁用所有仍基于 Manifest V2 的扩展，包括流行的广告拦截扩展 uBlock Origin。该公司计划在 2025 年底前完成消费者用户的迁移，并在 2027 年初关闭企业用户的 Manifest V2 扩展。 此举紧随 Google Chrome 对 Manifest V2 的弃用，标志着行业整体转向，将严重影响广告拦截扩展和用户选择。数百万依赖 uBlock Origin 拦截广告的 Edge 用户将不得不改用功能较弱的替代品（如 uBlock Origin Lite）或更换浏览器。 Edge 扩展商店中仅有 58 个高使用量扩展仍基于 Manifest V2，其中只有 3 个没有提供 Manifest V3 版本。微软将从本月开始默认禁用这些扩展，计划在 2025 年底前完成消费者用户的迁移，2027 年初关闭企业用户的 Manifest V2 扩展。

rss · Solidot · 8月8日 11:19

**背景**: 浏览器扩展是基于 Web 技术（如 HTML、CSS 和 JavaScript）构建的软件程序，用于自定义浏览体验。Manifest V2 和 V3 是扩展 API 规范的不同版本。Manifest V3 引入了更严格的安全和隐私控制，但通过限制 webRequest API 的使用来削弱广告拦截扩展的能力，而该 API 对于拦截网络请求至关重要。uBlock Origin 是一款依赖 Manifest V2 功能的流行开源广告拦截器，而 uBlock Origin Lite 是基于 Manifest V3 构建的功能较弱的版本。

## [115 网盘 API 开放平台将于 2026 年 8 月 9 日暂停服务](https://q.115.com/115/T976421.html#) ⭐️ 8.0/10

115 网盘 API 开放平台宣布将于 2026 年 8 月 9 日起暂停服务。所有依赖该 API 的第三方应用（如 NAS 设备和播放器）将受到影响。 此次暂停服务将破坏依赖 115 网盘 API 进行文件管理和流媒体播放的第三方集成生态。依赖 NAS 或直链播放器访问云存储的用户将失去这些功能，可能被迫寻找替代方案。 暂停服务将于 2026 年 8 月 9 日 0:00 生效，恢复时间待官方公告。该 API 提供文件上传、下载、分享、重命名、移动、删除、文件信息查询以及部分播放能力等功能。

telegram · zaihuapd · 8月8日 19:48

**背景**: NAS（网络附加存储）是一种连接到网络的专用存储设备，允许用户从多个设备存储和访问文件。它常用于备份照片、视频等数据，以及进行媒体流播放。直链是指直接指向文件真实存储地址的 URL，用户点击后无需经过中间页面或登录验证即可直接下载文件。许多第三方播放器利用 115 网盘等云存储服务的直链来直接播放内容。
