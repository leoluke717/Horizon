## [Firefox now the only major browser that supports uBlock Origin](https://www.pcworld.com/article/3212428/firefox-is-now-the-last-major-browser-that-still-supports-ublock-origin.html) ⭐️ 9.0/10

Google Chrome&\#x27;s adoption of Manifest V3 has effectively ended support for full ad-blocking extensions like uBlock Origin, leaving Firefox as the last major browser that still supports them. This shift alters the competitive dynamics of the browser market, potentially driving users who prioritize ad-blocking to switch to Firefox. It also underscores Google&\#x27;s influence over web standards and the limitations it imposes on extension capabilities. Manifest V3 restricts the webRequest API that uBlock Origin depends on, forcing a switch to the less capable declarativeNetRequest API. Firefox has committed to continuing support for Manifest V2 and the webRequest API, preserving full ad-blocking functionality.

hackernews · DemiGuru · Aug 14, 19:03 · [Discussion](https://news.ycombinator.com/item?id=49303202)

**Background**: Manifest V3 is the latest version of Chrome&\#x27;s extension platform, introduced by Google to improve security, privacy, and performance. However, it restricts certain APIs, particularly the webRequest API, which allows extensions to intercept and modify network requests. This change significantly limits the capabilities of ad-blocking extensions like uBlock Origin, which rely on that API to block ads before they load. Other Chromium-based browsers such as Microsoft Edge and Brave have also adopted Manifest V3, leaving Firefox as the only major browser that still supports the full-featured uBlock Origin.
