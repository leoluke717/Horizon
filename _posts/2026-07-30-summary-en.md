The GCC steering committee has officially adopted an AI policy that rejects contributions containing LLM-generated code or text that is considered legally significant, defined as approximately 15 lines. The policy allows LLM use for research, analysis, bug detection, and patch review, as long as the output is not included in contributions, and maintainers may accept LLM-generated test cases. This policy sets a clear precedent for open source projects grappling with the legal implications of AI-generated code. It could influence how other major projects handle contributions from large language models, impacting developers and the broader open source ecosystem. The policy defines &\#x27;legally significant&\#x27; as approximately 15 lines of code or text, which is the threshold for copyrightability. It explicitly does not prohibit using LLMs for research, analysis, bug finding, and patch review, and maintainers can choose to accept LLM-generated test cases.

rss · Solidot · Jul 29, 15:56

**Background**: GCC \(GNU Compiler Collection\) is a critical open source compiler suite used for compiling programs in languages like C, C++, and Fortran. Large language models \(LLMs\) such as GPT-4 can generate code, but the copyright status of AI-generated content is legally uncertain. This policy aims to protect GCC from potential copyright infringement claims by ensuring that all contributed code is authored by humans with clear copyright ownership.
