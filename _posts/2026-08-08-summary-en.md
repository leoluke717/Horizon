## [DeepMind WeatherNext AI Gives Extra Day of Hurricane Warning](https://www.solidot.org/story?sid=85042) ⭐️ 8.0/10

Google DeepMind&\#x27;s WeatherNext AI model, published in Nature, can predict hurricane paths with an extra day of lead time compared to existing models, and its three-day forecast accuracy matches the previous two-day accuracy. In a real-world test, it predicted Hurricane Melissa&\#x27;s landfall in Jamaica with 80% confidence five days in advance. This breakthrough could dramatically improve emergency preparedness and reduce casualties from hurricanes, as every extra hour of warning allows for better evacuation and resource allocation. It also demonstrates the potential of AI in meteorology, potentially transforming weather forecasting. The model was trained on vast amounts of general weather data rather than limited cyclone data, enabling it to generalize better. WeatherNext 2 can generate hundreds of forecast scenarios in under a minute using a single TPU, with resolution up to one hour.

**Background**: Traditional hurricane forecasting relies on physics-based models that simulate atmospheric dynamics. AI models like WeatherNext learn patterns from historical data, often achieving faster and more accurate predictions. ## [Microsoft Edge Enforces Manifest V3, Blocks uBlock Origin](https://www.solidot.org/story?sid=85038) ⭐️ 8.0/10

Microsoft Edge has announced it will gradually disable all remaining Manifest V2 extensions starting this month, effectively blocking popular ad-blocking extensions like uBlock Origin. The company plans to fully deprecate Manifest V2 for consumer users by the end of 2025 and for enterprise users by early 2027. This move follows Google Chrome&\#x27;s similar deprecation of Manifest V2, signaling a broader industry shift that will severely impact ad-blocking extensions and user choice. Millions of Edge users who rely on uBlock Origin for ad blocking will need to switch to less powerful alternatives like uBlock Origin Lite or change browsers. Only 58 high-use extensions in the Edge Add-On Store remain on Manifest V2, and only three of those lack a Manifest V3 version. Microsoft will begin disabling these extensions by default this month, with full deprecation scheduled for end of 2025 for consumers and early 2027 for enterprises.

rss · Solidot · Aug 8, 11:19

**Background**: Browser extensions are software programs that customize the browsing experience, built using web technologies like HTML, CSS, and JavaScript. Manifest V2 and V3 are different versions of the extension API specification. Manifest V3 introduces stricter security and privacy controls but also limits the capabilities of ad-blocking extensions by restricting the use of the webRequest API, which is essential for blocking network requests. uBlock Origin is a popular open-source ad blocker that relies on Manifest V2&\#x27;s capabilities, while uBlock Origin Lite is a less powerful version built on Manifest V3.

## [115 Cloud Drive API Open Platform Suspends Service from August 9, 2026](https://q.115.com/115/T976421.html#) ⭐️ 8.0/10

115 Cloud Drive API Open Platform announced that it will suspend service starting from August 9, 2026. This affects all third-party applications that rely on the API, such as NAS devices and media players. This suspension disrupts the ecosystem of third-party integrations that depend on 115 Cloud Drive&\#x27;s API for file management and streaming. Users who rely on NAS or direct-link players for accessing their cloud storage will lose these capabilities, potentially forcing them to seek alternative solutions. The suspension takes effect at 0:00 on August 9, 2026, and the resumption time is to be announced. The API provides functions including file upload, download, sharing, rename, move, delete, file info query, and some playback capabilities.

telegram · zaihuapd · Aug 8, 19:48

**Background**: NAS \(Network Attached Storage\) is a dedicated storage device connected to a network, allowing users to store and access files from multiple devices. It is commonly used for backing up photos, videos, and other data, as well as for media streaming. A direct link \(直链\) is a URL that points directly to a file&\#x27;s storage location, enabling users to download files without going through intermediate pages or login verification. Many third-party media players use direct links from cloud storage services like 115 to stream content directly.
