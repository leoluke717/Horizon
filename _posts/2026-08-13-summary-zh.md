## [GPT-5.6 Sol Ultrafast 实现 7 倍更快的 AI 推理](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai) ⭐️ 8.0/10

OpenAI 与 Cerebras 合作推出了 GPT-5.6 Sol Ultrafast 服务层，其推理速度比同类模型快达 7 倍，在 HLE 基准测试中完成 2500 道题仅需 11 小时，而 Claude Fable 5 需要 78 小时，同时保持了相当的准确性。 这一突破将复杂推理任务从数天缩短至一个工作日，使得更快的决策和更响应的 AI 产品成为可能。它解决了速度与智能之间的传统权衡，惠及依赖快速推理的 AI 研究人员、开发者和企业。 Ultrafast 模式由 Cerebras 的晶圆级引擎架构驱动，每秒可输出多达 750 个 token，处理速度比标准模式快达 14 倍。然而，社区评论指出，OpenAI 并未明确确认其准确性是否与 GPT-5.6 Sol 的非超快版本完全相同。

hackernews · pr337h4m · 8月13日 18:10 · [社区讨论](https://news.ycombinator.com/item?id=49289844)

**背景**: Cerebras 的晶圆级引擎（WSE）是一款拥有 90 万个 AI 优化核心、算力达 125 petaflops 的巨大芯片，专为大型 AI 模型设计。GPT-5.6 Sol 是 OpenAI 最智能的模型，Ultrafast 模式是 OpenAI API 中的一个新服务层。此次合作利用 Cerebras 的专用硬件加速 OpenAI 的前沿模型，实现了前所未有的推理速度。

## [宁夏发布补充耕地质量鉴定技术规范](https://www.chinanews.com.cn/gn/2026/08-13/10677158.shtml) ⭐️ 8.0/10

宁夏农业农村厅正式印发《宁夏补充耕地质量鉴定技术规范\(试行\)》，标志着补充耕地质量鉴定和验收工作进入制度化、规范化、标准化阶段。 该规范为补充耕地质量提供了刚性技术标准，有助于守住耕地质量底线，保障粮食安全。它也为其他地区制定类似规范树立了榜样。 该规范为试行版本，专门针对宁夏本地实际情况制定。它建立了补充耕地质量鉴定和验收的标准化流程。

rss · 中国新闻网 - 时政 · 8月13日 11:02

**背景**: 补充耕地是指通过土地整治项目新增的耕地，用于补偿建设占用的耕地。中国要求补充耕地的质量不得低于被占用耕地的质量。质量鉴定是确保补充耕地符合农业生产标准的重要环节。宁夏的规范为这一过程提供了本地化的技术标准。

## [吉林设立百亿富民产业资金池](https://www.chinanews.com.cn/cj/2026/08-13/10677150.shtml) ⭐️ 8.0/10

吉林省宣布设立总规模不低于 100 亿元的‘富民产业’资金池，并创新推出‘整村授信’模式，提供最高 300 万元的信用贷款、最高 5000 万元的担保贷款，担保费率不超过 0.8%，贷款期限最长可达 10 年。 这一举措为吉林省乡村振兴提供了大规模资金支持，有望推动农业发展和农民增收。优惠的信贷条件可大幅改善农户和农村企业的融资渠道，解决农村经济发展的关键瓶颈。 资金池专门用于‘富民产业’，聚焦惠农产业。‘整村授信’模式以自然村为单位进行授信，银行根据整村信用状况为农户提供贷款，具体额度、费率、期限如公告所示。

rss · 中国新闻网 - 财经 · 8月13日 11:04

**背景**: 乡村振兴是中国国家重点战略，旨在发展农村地区。由于缺乏抵押物和信用记录，融资难一直是农民和农村企业面临的主要挑战。‘整村授信’是一种银行以自然村为单位进行信用评估的模式，使农户能够基于整村信用获得优惠贷款。‘富民产业’资金池是专门支持直接惠农产业的金融工具。

## [美国对进口无人机征收 10%至 100%关税](https://www.chinanews.com.cn/gj/2026/08-14/10677339.shtml) ⭐️ 8.0/10

2026 年 8 月 13 日，美国总统特朗普签署公告，以国家安全为由对进口无人机及零部件征收 10%至 100%的从价关税，立即生效。 这一关税政策可能大幅增加无人机进口商和制造商的成本，推高消费者价格，并冲击严重依赖中国制造的全球无人机供应链。 关税幅度为 10%至 100%从价税，适用于成品无人机及其零部件，立即生效。公告明确以国家安全为由实施该措施。

rss · 中国新闻网 - 国际 · 8月13日 22:28

**背景**: 无人机广泛应用于商业、娱乐和军事领域。大多数消费级和商用无人机在中国制造，大疆等公司主导全球市场。美国是无人机主要进口国，这些关税可能重塑行业贸易格局。

## [特朗普签署备忘录，允许私企海外网络攻击](https://www.bloomberg.com/news/articles/2026-08-13/trump-enlists-private-sector-to-boost-cyber-offensive-arsenal) ⭐️ 8.0/10

特朗普总统签署备忘录，授权私营企业在政府监督下开展海外监控和网络攻击，改变了以往只有政府机构才能从事此类活动的规则。 此举通过利用私营部门资源扩大了美国的网络进攻能力，可能加快针对外国犯罪网络的行动规模和速度，但也引发了对监督和问责的担忧。 国土安全部将负责运行该项目，并与司法部协调监督。参与企业须维持至少 100 万美元的保证金或托管款，如不遵守合同约定，该款项将被没收。

telegram · zaihuapd · 8月13日 05:10

**背景**: 传统上，进攻性网络行动仅由国家安全局或网络司令部等政府机构执行。这份备忘录改变了这一模式，允许私营企业在政府支持下行动，模糊了公共与私营部门在国家安全中的角色界限。

## [DeepSeek-V4-Pro 正式版上线，API 峰谷定价](https://api-docs.deepseek.com/zh-cn/updates) ⭐️ 8.0/10

DeepSeek 正式发布了 V4-Pro 模型，覆盖 APP、网页端和 API，并宣布 API 将实行峰谷定价，闲时价格为高峰时段的一半，新价格于 2026 年 8 月 17 日生效。 这种定价模式可以大幅降低在非高峰时段使用 API 的开发者的成本，可能改变 AI API 服务的消费方式。同时，新推出的思考模式档位让用户对推理深度有了更精细的控制。 V4-Pro 模型增强了智能体能力，原生支持 Responses API 格式，并适配 Codex。V4-Pro 和 V4-Flash 的思考模式新增了 low、high、max 三档。

telegram · zaihuapd · 8月13日 11:12

**背景**: Responses API 是 OpenAI 开发的一种 AI 模型交互格式，允许开发者使用统一接口进行聊天补全等任务。Codex 是 OpenAI 推出的 AI 编程助手，能够通过自然语言指令帮助开发者完成代码编写、修改和调试。DeepSeek 支持这些格式意味着开发者可以将 DeepSeek 模型集成到现有的兼容 OpenAI API 的工作流程中。
